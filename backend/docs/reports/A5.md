### A5.1: `find_banned`, the banned-phrase checker

**What & why.** `find_banned(text, lang=None)` finds the judgmental phrases of arch 6.9 (D33) in Romanian and English text and returns each match with its offsets in the original text. A6 uses it on Claude's final reply (a hit → regenerate once, then the template), A7 on the spoken question, bomboe's B13 on every notification template, A10 for "0 banned phrases in generated questions", and D3 for acceptance #1. The policy is the approved Q1: every standalone «iar» and «de ce» is a hit, even in the neutral sense, because a missed hit shows judgmental text to the user while a false hit only costs one regeneration.

**Dependency change after plan approval (boss decision, D48).** There is one shared folding function, C1.1's `app/i18n/text.py`. A5.1 doesn't fold by itself: it imports `fold_char` and keeps only the offset map, the patterns and the word boundaries. My contract requirements a–f went to C1 and are built in. The C1.1 gaps (spacing diacritics, invisible fillers, some dash and apostrophe look-alikes) first had integration tests marked `xfail(strict=True, reason="C1.1-fix")`. C1.1-fix was merged (7c98d8f) during this step: the branch was rebased, the 20 tests went from XFAIL to strict XPASS (20 failures, as intended), and they are now normal tests that pass. The plan records the change ([`plans/A5.md`](../plans/A5.md), header + §2 + §3).

**Contract impact.** New public API in `app/agent/style.py` (not in arch §15):
```python
LANGS: Final = ("ro", "en")
BANNED_PHRASES: Final[Mapping[str, tuple[str, ...]]]   # read-only; arch 6.9 in order + «irosi» (Q3)
@dataclass(frozen=True, slots=True)
class BannedMatch: phrase: str; lang: str; start: int; end: int; text: str   # text == original[start:end]
def find_banned(text: str, lang: str | None = None) -> list[BannedMatch]
```
- `lang="ro"` / `"en"` (or F2's `Language`) checks that list; `None` checks both. **A6 should pass `None`** (Claude may answer in the other language after the user switches).
- Matches are sorted by `(start, end)`; every occurrence is returned. An unknown `lang` → `ValueError`; a non-`str` text → `TypeError`.
- Consumers: A6, A7, A10, D3 (David G.), **B13 (bomboe)**. Nothing existing changes.

**Implementation.** `app/agent/style.py`.
- `_FORMS` maps each canonical phrase to its folded regex forms; in a form, a space means "one or more spaces or hyphens". `BANNED_PHRASES` is derived from its keys, so there is one source.
- Each phrase compiles once at import to `(?<![^\W_])(?:forms)(?![^\W_])`: only letters and digits are word characters, so `_`, apostrophes, hyphens and punctuation are boundaries. Linear patterns (no nested quantifiers).
- `find_banned` folds the text **one character at a time with C1's `fold_char`**, keeps for every folded position the index of its original character, and runs the patterns on the folded text. Each match maps back as `start = origin[m.start()]`; `end` = the next kept character, so a trailing combining mark or invisible stays inside the span, and at least one past the last matched character.
