### C1.1: `fold` / `fold_char` + RO/EN formats (`app/i18n/text.py`, `app/i18n/format.py`)

**What & why.** These are the two language primitives with no F2 dependency, so they come first. A5 is blocked on `fold` (`find_banned`, A5.1) and on `format_money` (A5.3). C2, C4 and C5 will match on `fold`, and B13 / A4 format numbers with `format.py`.

**Contract impact.** 🆕 public functions (not in arch §15 yet; the doc line is proposed in plan §5.2):

```python
app.i18n.text.fold_char(ch: str) -> str          # exactly one character in; "", 1 or more characters out; never raises on a code point
app.i18n.text.fold(text: str) -> str             # == "".join(fold_char(c) for c in text)
app.i18n.format.format_money(amount: Decimal | int, lang: str) -> str                    # "10.000 lei", "30,40 lei", "-30,40 lei", "500 lei"
app.i18n.format.format_pct(value: Decimal | float | int, lang: str, *, decimals: int = 0) -> str   # "77%", "12,5%"
app.i18n.format.format_date(day: date, lang: str, *, with_year: bool = True, with_weekday: bool = False) -> str  # "luni, 15 iunie 2026"
```
`lang` is `"ro"` / `"en"`; F2's `Language` members work as they are (StrEnum). Readers: A5, A4, B13, A11, C2, C4, C5.

**`fold` contract** (the boss's and A5's refinements, all built in). Per character:
1. Apostrophe and dash variants are unified **before** NFKD: `’ ‘ ʼ ´ ` ‛ ʻ ′ ＇` → `'`, and `‐ ‑ ‒ – — ― − ﹘ ﹣ －` → `-`. NFKD alone would turn `´` into a space plus an accent.
2. NFKD.
3. Every **Mn, Me and Cf** character is dropped: marks, enclosing marks, and all format characters (ZWSP/ZWJ/ZWNJ, word joiner, soft hyphen, BOM, LRM/RLM/ALM, bidi controls).
4. Anything `isspace()` becomes one plain space, so NBSP, `\n`, `\t` and `\r` are mapped, never dropped.
5. Casefold.

Nothing else happens: no strip, no collapsing; punctuation, digits and underscores stay. A **single pass** is already a fixed point for every assigned code point (checked exhaustively, see below), so no second pass is needed. `fold_char` has an `lru_cache(maxsize=4096)`.

**Deviations from the approved plan** (each one needed by the contract above, nothing else changed):

| Plan said | Now | Why |
|---|---|---|

C1.2's alias test will use the strict alphanumeric key from the plan, so nothing is lost |

| — | 🆕 `fold_char` | A5 needs the per-character form |

**Implementation.**
- `text.py`: a 19-entry punctuation table checked on the original character and again on NFKD's output. Mn, Me and Cf are dropped by category, `isspace()` becomes `" "`, then casefold. `fold` maps `fold_char` over the text.
- `format.py`: one frozen `_Locale` per language (separators, months, weekdays). Rounding is `quantize(…, ROUND_HALF_UP)` in an explicit `Context(prec=28, traps=[InvalidOperation])`, and `-0` becomes `0`. Grouping uses Python's own `format(x, ",.2f")`, with the separators then swapped by `str.translate`. Strict type checks: no float/bool money, no datetime.

**Self-review findings** (how-we-work §5), all fixed:
1. **Tool-induced invisible characters.** Writing the tests turned every `\uXXXX` escape into the literal character (ZWSP, BOM, cedillas…): unreviewable, and it defeats "explicit escapes". The files were rewritten through placeholders. A final audit lists every non-ASCII character in the 4 files: only intended Romanian letters and `… → · ─`, and all of it is NFC.
2. **The surrogate property was hollow**: `st.characters()` never generates `Cs`. Fixed with the mixed strategy (Cs 175, Mn 81, Me 6, Cf 3 in a 100-example sample).
3. `ruff` PT014 flagged `"\ud800"` / `"\udfff"` as duplicates (it can't represent lone surrogates) → written as `chr(0xD800)` / `chr(0xDFFF)`.
4. mypy rejected `str.maketrans(dict)` (dict invariance) → the two-string form.
5. `# fmt: skip` doesn't work on keyword arguments → month / weekday tuples moved to module constants.
6. A cedilla `Ş` in a docstring example → reworded, so `app/i18n` has no cedilla at all.

**Alias rules** (plan, with one addition caused by C1.1-fix):
1. The folded canonical name is an alias.
2. Aliases are unique after `fold` within a merchant.
