### F1.1: project, tooling, app factory, `GET /api/health`

**What & why.** The runnable, testable empty app everyone builds on (F1 blocks bomboe's B2/F3 and danutu's E*). It's uv + `pyproject.toml` + `uv.lock` with every dependency of work-breakdown §0.1, so nobody touches pyproject mid-hackathon. The ruff / mypy / pytest / coverage config, the Makefile targets and the `create_app()` factory with a `/api` router + `GET /api/health` are all in place.

**Contract impact.**
- 🆕 The app is started through the factory: `uvicorn app.main:create_app --factory --workers 1` (no module-level `app`). This affects bomboe's Dockerfile (HANDOFFS **H-2**).
- `requirements.txt` is generated from `uv.lock` (`make requirements`) and checked by `make check` (H-2).
- `backend/docker-compose.yml` has only `db-test` for `make db-up` (HANDOFFS **H-1**; bomboe's B1 replaces it).
- `GET /api/health` → `200 {"status":"ok"}` (public).

**Tooling decisions (in `pyproject.toml`).**
- **ruff** rules `E W F I B UP SIM RUF ASYNC S DTZ PT TID`; `docs/` excluded (ruff 0.17 formats Python blocks inside Markdown, and the arch doc's snippets are pseudocode).
- **`TID251` bans `datetime.now/utcnow/today`, `date.today`, `time.time` everywhere except `app/clock.py`**: work-breakdown 0.3 rule 3 is now enforced by the linter (probe below).
- **mypy:** a baseline for everything (`check_untyped_defs`, `strict_equality`, `no_implicit_optional`, `warn_unused_ignores`…) + the full strict flag set on `app.domain/engine/context/agent` and F1's own modules (mypy's `strict` only works globally, so the flags are listed one by one); pydantic plugin.
- **pytest:** `--strict-markers --strict-config`, default `-m "not live"`, markers `db api ws live slow`, `asyncio_mode = auto`, `xfail_strict`, **`filterwarnings = error`** (a third-party warning gets an explicit, commented ignore), coverage on `app/` (report only).
