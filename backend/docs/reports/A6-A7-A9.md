# A6 / A7 / A9 · Agent loop, proactive runs, deterministic fallbacks: report (fast mode)

**Files.** `app/agent/loop.py` (A6), `app/agent/proactive.py` (A7), `app/agent/fallbacks.py` (A9),
`tests/fakes/fake_agent_services.py`, `tests/unit/agent/test_{loop,proactive,fallbacks}.py`.
Fast mode: no plan approval, no independent review, no mutation testing.

## Decisions
- **Ports, not direct calls.** The loop talks to the backend through `AgentServices`
  (`setup`, `history`, `execute_tool`, `finish_run`); proactive adds `get_event`,
  `save_assistant_message`, `mark_event_asked`, `create_notification` (`ProactiveServices`).
  `setup()` returns `RunSetup(language, snapshot, tools, open_question, pots)`, built **once**
  per run (D46). B9/B8 wire the real adapters with `set_agent_services` / `set_proactive_services`
  (or pass `services=`).
- **Async.** `run_agent` and `run_proactive` are `async` (the S0 stubs were sync).
  `run_proactive` returns `None` when nothing was said (not pending, in flight, or a non-question
  event while Claude is down: left pending, arch 11).
- **Stop reasons** (whitelist): `tool_use` → loop; `end_turn` → reply; anything else → template
  (`refusal` → "refusal", the rest → "llm_down"); the iteration limit → "loop_limit".
- **Defence:** a tool not in this run's list is refused in the loop, before the executor (D22).
- **Banned phrases:** a hit → one regeneration (assistant turn + a style-check user turn), then
  the template. A filled template is never re-checked.
- **History:** last 20; leading assistant turns dropped; the user message saved by B9 isn't
  appended twice; a run with no user message gets a synthetic user turn (no prefill).
- **UI collection:** chips = the last successful `show_quick_replies.options` (≤ 4, ≤ 80 chars);
  cards = `action_card` in a tool result's JSON; `plan_changed` = a `plan` key in a result.
- **A9:** chips map to the same tool calls Claude makes, through the same executor, so the
  end state is the LLM path's (test: Scene A, 100 + 400). Unknown text → the LLM-down reply,
  nothing changed.
